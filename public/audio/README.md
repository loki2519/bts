# Licensed audio files

Place audio files you own or are licensed to distribute in this folder.

The player looks for a lowercase, hyphenated `.mp3` filename based on each track title. For example, `Spring Day` uses `spring-day.mp3` and `Blood Sweat & Tears` uses `blood-sweat-tears.mp3`.

Alternatively, add an `audioUrl` field to a playlist entry to use a different approved local or CDN audio URL.
